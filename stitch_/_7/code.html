工作内容 / 岗位职责

核心研发部门直聘

你将加入智航未来基础大模型实验室（LLM Research Lab），同顶级科学家和工程架构师并肩，主导从基座模型预训练至千亿级参数多模态端到端落地。具体职责涵盖：

01

千亿级大模型预训练与优化

深入参与千亿级多模态大语言模型（LLM）的预训练数据飞轮构建、高质量合成数据清洗、指令微调（SFT）与基于人类反馈的强化学习（RLHF / DPO）算法迭代。

02

垂直行业 Agent 与 RAG 体系构建

负责复杂业务场景下的自主 Agent 工作流编排、工具调用推理（Tool Use / Function Calling）以及基于语义图谱的高精度 RAG 知识检索增强引擎技术攻坚。

03

前沿学术突破与论文发表

持续探索国际前沿学术进展（包括长上下文建模、思维链 CoT、自省式对齐等），协助发表顶级人工智能学术会议论文（NeurIPS, ICML, ICLR, CVPR, ACL 等）并申请核心发明专利。
