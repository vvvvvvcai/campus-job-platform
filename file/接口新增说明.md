# 接口新增说明

> 本文件记录联调期间新增的后端接口（经项目 owner 确认后添加），说明每个接口的用途、调用方式与使用页面。
> 最后更新：2026-09-16

## 一、GET /api/job/company/list —— 企业职位列表

- **所属服务**：job-service（职位服务）
- **用途**：企业端「职位管理」页获取**本企业发布的全部职位**（含待审核/已关闭），此前没有该接口，企业端无法看到自己的职位
- **请求方式**：GET
- **请求头**：
  - `X-User-Id`：当前登录用户 ID（网关注入）
- **请求参数**：
  - `companyId`（必填，Long）：企业 ID
- **响应**：`Result<List<JobInfoVO>>`，按创建时间倒序，包含职位全部字段 + 企业名称
- **使用页面**：[EnterpriseJobs.vue](fronted/src/views/EnterpriseJobs.vue)（列表展示、编辑入口、上/下架）
- **权限说明**：网关登录鉴权（任何登录用户可调；数据以 companyId 为准，学生侧不可见该页面入口）
- **验证状态**：✅ 已验证（companyId=3 返回 4 条、companyId=4 返回 3 条）

## 二、GET /api/application/resume/{applicationId} —— 企业查看候选人简历（脱敏）

- **所属服务**：application-service（投递服务）
- **用途**：企业 HR 按**投递记录**查看候选人简历。此前简历详情接口有归属校验（只有简历本人能看），HR 查不了候选人简历；本接口绕开归属校验改为角色校验
- **请求方式**：GET
- **请求头**：
  - `X-User-Id`：当前登录用户 ID（网关注入）
  - `X-User-Role`：用户角色（网关注入；仅 1-企业HR / 2-管理员 可调，学生角色返回「无权查看候选人简历」）
- **路径参数**：
  - `applicationId`：投递记录 ID（由投递记录关联到对应简历）
- **响应**：`Result<ResumeInfoVO>`，简历全部字段，其中 **phone 已脱敏**（138****0002 格式），保护候选人隐私
- **使用页面**：
  - [Candidates.vue](fronted/src/views/Candidates.vue) 候选人列表「查看简历」按钮 → 弹窗展示
  - [ApplicationProcess.vue](fronted/src/views/ApplicationProcess.vue) 处理流转页「查看简历」按钮 → 弹窗展示
  - 共用弹窗组件：[CandidateResumeModal.vue](fronted/src/components/CandidateResumeModal.vue)
- **验证状态**：✅ 已验证（HR 角色 200 返回脱敏简历；学生角色 500「无权查看候选人简历」；无 token 401）

## 三、POST /api/upload/image —— 图片上传（本地文件）

- **所属服务**：user-service（文件存储在本机 `user-service/uploads/yyyyMMdd/` 目录）
- **用途**：企业认证页营业执照/身份证图片、简历附件图片的本地上传，返回可直接访问的图片 URL
- **请求方式**：POST（multipart/form-data，字段名 `file`）
- **请求头**：`X-User-Id`（网关注入，需登录）
- **限制**：仅 jpg/jpeg/png/gif/webp，最大 5MB（user-service yml 配 multipart 10MB 上限）
- **响应**：`Result<String>`，返回 `/uploads/yyyyMMdd/xxx.png` 形式的相对 URL
- **图片访问**：GET `/uploads/**` 经网关路由到 user-service 静态目录（AuthFilter 白名单，无需登录）
- **使用页面**：
  - [EnterpriseCert.vue](fronted/src/views/EnterpriseCert.vue)：营业执照（存 licenseUrl）、身份证正反面（上传+预览；**注意：t_company 无身份证字段，暂不落库**）
  - [ResumeEditor.vue](fronted/src/views/ResumeEditor.vue)：附件与作品图片（存 t_resume.attachments JSON 数组）
- **验证状态**：✅ 已验证（上传返回 URL、网关访问图片 200、无 token 401）
