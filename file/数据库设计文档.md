## 二、数据库概述

本数据库为"大学生实习就业综合服务平台"提供数据存储支持，包含9张核心业务表，覆盖用户管理、企业信息、职位发布、简历管理、投递流程、消息通知、智能推荐等功能模块。

### 2.1 表清单

| 序号 | 表名 | 表说明 | 所属服务 |
|------|------|--------|----------|
| 1 | t_user | 用户基本信息表 | user-service |
| 2 | t_company | 企业信息表 | company-service |
| 3 | t_job | 职位信息表 | job-service |
| 4 | t_resume | 学生简历表 | application-service |
| 5 | t_application | 投递记录表 | job-service |
| 6 | t_favorite | 收藏记录表 | job-service |
| 7 | t_message | 站内信表 | user-service |
| 8 | t_user_profile | 用户画像标签表 | recommend-service |
| 9 | t_recommend_log | 推荐记录日志表 | recommend-service |

## 三、表结构详细设计

### 3.1 用户基本信息表 (t_user)

**表说明**：存储平台所有用户的基础账号信息

| 字段名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| id | BIGINT | 是 | 自增 | 用户ID，主键 |
| phone | VARCHAR(20) | 是 | - | 手机号，唯一 |
| password | VARCHAR(255) | 是 | - | 密码(BCrypt加密) |
| nickname | VARCHAR(50) | 否 | NULL | 昵称 |
| avatar | VARCHAR(255) | 否 | NULL | 头像URL |
| role | TINYINT | 是 | 1 | 角色: 1-学生 2-企业 3-管理员 |
| status | TINYINT | 是 | 1 | 状态: 0-禁用 1-正常 |
| last_login_time | DATETIME | 否 | NULL | 最后登录时间 |
| created_at | DATETIME | 是 | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | 是 | CURRENT_TIMESTAMP | 更新时间 |
| is_deleted | TINYINT | 是 | 0 | 逻辑删除: 0-未删除 1-已删除 |

**索引**：
- `PRIMARY KEY (id)` - 主键
- `UNIQUE KEY uk_phone (phone)` - 手机号唯一
- `KEY idx_role (role)` - 角色索引
- `KEY idx_status (status)` - 状态索引

---

## 七、注意事项

1. 所有表均使用`utf8mb4`字符集，支持emoji等特殊字符
2. 敏感字段（如密码）使用BCrypt加密存储
3. 逻辑删除字段`is_deleted`用于软删除，避免物理删除
4. 时间字段统一使用`DATETIME`类型
5. 金额字段使用`DECIMAL`类型避免精度问题
6. 建议定期备份数据库，确保数据安全
