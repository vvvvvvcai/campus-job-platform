## 二、项目概述

### 2.1 项目背景
随着高校毕业生数量逐年增加，学生就业压力持续增大。传统校园招聘存在信息不对称、流程繁琐、效率低下等问题。本项目旨在构建一个全国性的大学生实习就业综合服务平台，连接学生、高校与企业，提供一站式招聘求职服务。

### 2.2 项目目标
| 目标维度 | 具体目标 |
|----------|----------|
| 学生端 | 便捷完善简历、快速找到匹配岗位、实时跟踪面试进度 |
| 企业端 | 精准触达目标人才、高效管理招聘流程、降低招聘成本 |
| 平台端 | 汇聚优质资源、建立信用体系、实现数据驱动运营 |

### 2.3 开发约束
- **开发周期**：1-2个月
- **技术架构**：Spring Boot + Spring Cloud 微服务架构
- **终端适配**：仅PC端（响应式Web设计）
- **第三方集成**：短信验证码、邮件通知

### 4.2 功能模块详细说明

| 功能点 | 说明 | 优先级 |
|--------|------|--------|
| 手机号注册 | 短信验证码注册，区分学生/企业身份 | P0 |

| 功能点 | 说明 | 优先级 |
|--------|------|--------|

## 六、微服务架构设计

### 6.1 服务拆分方案（5个核心服务）

| 服务名称 | 职责范围 | 技术栈 |
|----------|----------|--------|
| gateway-service | API网关、路由转发、鉴权 | Spring Cloud Gateway |
| user-service | 用户注册、登录、认证 | Spring Boot + MyBatis |
| company-service | 企业认证、信息管理 | Spring Boot + MyBatis |
| job-service | 职位发布、搜索、收藏 | Spring Boot + MyBatis + Redis |
| application-service | 简历投递、进度跟踪 | Spring Boot + MyBatis |

### 6.2 基础设施组件

| 组件 | 用途 |
|------|------|
| Nacos | 服务注册与配置中心 |
| MySQL | 关系型数据库（每服务独立库） |
| Redis | 缓存、分布式锁 |
| RabbitMQ | 异步消息（邮件、短信） |

### 6.3 服务依赖关系

```
                    ┌─────────────┐
                    │    Nacos    │
                    │  (注册/配置) │
                    └──────┬──────┘
                           │
┌─────────────┐            │            ┌─────────────┐
│   客户端    │◄───────────┼───────────►│   管理后台  │
└──────┬──────┘            │            └──────┬──────┘
       │                   │                   │
       ▼                   ▼                   ▼
┌─────────────┐
│   Gateway   │
└──────┬──────┘
       │
       ├──────► user-service
       ├──────► company-service
       ├──────► job-service
       └──────► application-service
```

## 十、风险与应对

| 风险项 | 影响 | 应对措施 |
|--------|------|----------|
| 开发周期紧张 | 功能不完整 | 优先保证P0功能，P1/P2可延期 |
| 微服务复杂度 | 开发效率低 | 基础服务复用，减少重复开发 |
| 数据安全问题 | 用户隐私泄露 | 全链路加密，脱敏处理 |
| 高并发场景 | 系统性能不足 | 预留扩容方案，监控告警 |
