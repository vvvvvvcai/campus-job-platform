# 大学生实习就业综合服务平台 - 前端页面设计提示词

## 一、页面总览

| 模块 | 页面数量 | 页面名称 |
|------|----------|----------|
| 首页 | 1 | 平台首页 |
| 用户模块 | 4 | 登录、注册、个人中心、修改密码 |
| 企业模块 | 2 | 企业认证、企业管理中心 |
| 职位模块 | 4 | 职位搜索、职位详情、发布职位、职位管理 |
| 投递模块 | 5 | 我的简历、投递记录、投递详情、收到的投递、投递处理 |
| 推荐模块 | 1 | 推荐职位 |
| **合计** | **17** | - |

## 二、公共组件

### 2.1 顶部导航栏
```
设计一个现代化的顶部导航栏，包含：
- 左侧：平台Logo和名称"校园就业综合服务平台"
- 中间：导航菜单（首页、职位搜索、推荐职位）
- 右侧：用户头像、用户名、下拉菜单（个人中心、我的投递、退出登录）
- 整体风格：简洁专业，蓝色主色调，白色背景
- 响应式设计，支持移动端
```

### 2.2 页脚
```
设计一个简洁的页脚，包含：
- 平台简介
- 快速链接（关于我们、联系方式、隐私政策）
- 版权信息
- 整体风格：深色背景，白色文字
```

## 三、用户模块

### 3.1 登录页面 (Login)
```
设计一个简洁的登录页面，包含：
- 左侧：平台Logo和宣传语"开启你的职业梦想"
- 右侧：登录表单
  - 手机号输入框（带国家区号选择）
  - 密码输入框（带显示/隐藏切换）
  - 记住密码复选框
  - 登录按钮（蓝色渐变）
  - 忘记密码链接
  - 注册链接
- 整体风格：现代简约，左右分栏布局，浅灰背景
- 移动端：单栏布局，表单居中
```

### 3.2 注册页面 (Register)
```
设计一个清晰的注册页面，包含：
- 左侧：平台Logo和宣传语"加入我们，找到理想工作"
- 右侧：注册表单
  - 手机号输入框（带验证码发送按钮）
  - 验证码输入框
  - 密码输入框（带强度提示）
  - 确认密码输入框
  - 用户名输入框
  - 角色选择（学生/企业）
  - 注册按钮（蓝色渐变）
  - 已有账号？登录链接
- 整体风格：现代简约，左右分栏布局
```

### 3.3 个人中心 (Profile)
```
设计一个功能完整的个人中心页面，包含：
- 顶部：用户头像（可上传）、用户名、角色标签
- 信息卡片：
  - 基本信息（姓名、性别、手机、邮箱）
  - 求职意向（期望城市、行业、职位、薪资）
  - 教育背景（学校、专业、学历、毕业年份）
- 编辑按钮：点击可编辑个人信息
- 整体风格：卡片式布局，白色卡片，浅灰背景
```

### 3.4 修改密码 (ChangePassword)
```
设计一个简洁的密码修改页面，包含：
- 表单居中显示
- 当前密码输入框
- 新密码输入框（带强度指示器）
- 确认新密码输入框
- 提交按钮
- 整体风格：简洁表单，白色背景卡片
```

## 四、企业模块

### 4.1 企业认证 (CompanyAudit)
```
设计一个专业的企业认证页面，包含：
- 认证状态提示（未认证/审核中/已认证）
- 认证表单：
  - 企业名称输入框
  - 统一社会信用代码输入框
  - 企业行业下拉选择
  - 企业规模下拉选择
  - 所在城市输入框
  - 联系人输入框
  - 联系电话输入框
  - 企业简介文本域
  - 营业执照上传区域
- 提交审核按钮
- 整体风格：专业商务风格，蓝色主色调
```

### 4.2 企业管理中心 (CompanyCenter)
```
设计一个企业管理中心仪表板，包含：
- 顶部统计卡片：
  - 发布职位数
  - 收到投递数
  - 待处理投递
  - 今日新增投递
- 快捷操作：
  - 发布新职位按钮
  - 查看所有投递按钮
- 最近投递列表（预览）
- 整体风格：仪表板布局，数据可视化
```

## 五、职位模块

### 5.1 职位搜索 (JobSearch)
```
设计一个功能强大的职位搜索页面，包含：
- 顶部搜索栏：
  - 关键词搜索框（带搜索图标）
  - 城市选择下拉
  - 职位类别下拉
  - 薪资范围滑块
  - 学历要求下拉
  - 经验要求下拉
  - 搜索按钮
- 搜索结果区域：
  - 结果统计（共找到XX个职位）
  - 排序选项（最新、薪资最高、距离最近）
  - 职位卡片列表：
    - 职位名称
    - 公司名称
    - 薪资范围
    - 城市
    - 学历要求
    - 经验要求
    - 发布时间
    - 收藏按钮
- 分页器
- 整体风格：现代简约，白色卡片，浅灰背景
```

### 5.2 职位详情 (JobDetail)
```
设计一个信息丰富的职位详情页面，包含：
- 顶部信息卡片：
  - 职位名称（大标题）
  - 薪资范围（醒目显示）
  - 公司名称（可点击跳转）
  - 工作城市
  - 职位类别
  - 发布时间
  - 收藏按钮
  - 投递简历按钮（蓝色主按钮）
- 职位描述区域：
  - 工作内容
  - 任职要求
  - 福利待遇
- 公司信息卡片：
  - 公司名称
  - 企业规模
  - 所属行业
  - 公司简介
- 相似职位推荐
- 整体风格：详情页布局，信息层次清晰
```

### 5.3 发布职位 (JobPublish)
```
设计一个专业的职位发布页面，包含：
- 表单布局：
  - 职位标题输入框
  - 职位类别下拉选择
  - 工作城市输入框
  - 薪资范围（最低-最高）
  - 学历要求下拉
  - 经验要求下拉
  - 工作类型单选（全职/实习/兼职）
  - 招聘人数输入
  - 职位描述富文本编辑器
  - 任职要求富文本编辑器
  - 福利待遇标签选择
- 预览功能：右侧实时预览
- 发布按钮
- 整体风格：表单设计，专业商务风格
```

### 5.4 职位管理 (JobManage)
```
设计一个职位管理列表页面，包含：
- 顶部操作栏：
  - 搜索框
  - 状态筛选（全部/招聘中/已暂停/已关闭）
  - 发布新职位按钮
- 职位列表表格：
  - 职位名称
  - 发布时间
  - 投递数量
  - 浏览量
  - 状态标签
  - 操作按钮（编辑/暂停/关闭/删除）
- 分页器
- 整体风格：管理后台风格，表格布局
```

### 5.5 我的收藏 (FavoriteList)
```
设计一个收藏列表页面，包含：
- 收藏职位卡片列表：
  - 职位名称
  - 公司名称
  - 薪资范围
  - 城市
  - 取消收藏按钮
- 空状态提示（暂无收藏职位）
- 分页器
- 整体风格：卡片列表，简洁明了
```

## 六、投递模块

### 6.1 我的简历 (ResumeManage)
```
设计一个简历管理页面，包含：
- 简历列表：
  - 简历卡片（标题、更新时间、是否默认）
  - 设置默认按钮
  - 编辑按钮
  - 删除按钮
- 新建简历按钮
- 简历预览区域：
  - 基本信息
  - 求职意向
  - 教育背景
  - 专业技能
  - 工作经历
  - 项目经历
- 整体风格：卡片式布局，清晰易读
```

### 6.2 简历编辑 (ResumeEdit)
```
设计一个简历编辑页面，包含：
- 分步表单：
  - 第一步：基本信息（姓名、性别、出生日期、手机、邮箱）
  - 第二步：求职意向（期望城市、行业、职位类型、薪资）
  - 第三步：教育背景（学校、专业、学历、毕业年份）
  - 第四步：技能特长（技能标签选择）
  - 第五步：工作经历（可添加多段）
  - 第六步：项目经历（可添加多个）
- 进度指示器
- 保存按钮
- 整体风格：分步表单，清晰引导
```

### 6.3 投递记录 (ApplicationList)
```
设计一个投递记录页面，包含：
- 状态筛选标签（全部/待查看/已查看/面试邀请/不合适/已录用）
- 投递列表：
  - 职位名称
  - 公司名称
  - 投递时间
  - 状态标签（不同颜色）
  - 查看详情按钮
- 空状态提示
- 分页器
- 整体风格：列表布局，状态颜色区分
```

### 6.4 投递详情 (ApplicationDetail)
```
设计一个投递详情页面，包含：
- 投递状态时间线：
  - 投递成功
  - HR查看
  - 面试邀请（如有）
  - 面试结果（如有）
- 职位信息卡片
- 投递简历信息
- 面试信息（如有）：
  - 面试时间
  - 面试地址
  - 联系人
  - 联系电话
- HR备注
- 整体风格：时间线布局，状态清晰
```

### 6.5 收到的投递 (ReceivedApplications)
```
设计一个企业端投递管理页面，包含：
- 顶部统计：
  - 总投递数
  - 待处理数
  - 今日新增
- 筛选区域：
  - 职位筛选下拉
  - 状态筛选下拉
- 投递列表：
  - 求职者姓名
  - 应聘职位
  - 投递时间
  - 状态标签
  - 操作按钮（查看简历/安排面试/不合适）
- 批量操作按钮
- 分页器
- 整体风格：管理后台风格，数据清晰
```

### 6.6 投递处理 (ApplicationHandle)
```
设计一个投递处理弹窗/页面，包含：
- 求职者信息概览
- 简历预览链接
- 处理表单：
  - 状态选择（待查看/已查看/面试邀请/不合适/已录用）
  - HR备注文本域
  - 面试信息（选择面试邀请时显示）：
    - 面试时间选择器
    - 面试地址输入
    - 联系人输入
    - 联系电话输入
- 确认提交按钮
- 整体风格：弹窗或侧边栏表单
```

## 八、通用样式规范

### 8.1 颜色规范
```
- 主色调：#1890FF（蓝色）
- 成功色：#52C41A（绿色）
- 警告色：#FAAD14（橙色）
- 危险色：#FF4D4F（红色）
- 文字色：#333333（主文字）、#666666（次文字）、#999999（辅助文字）
- 背景色：#F5F5F5（页面背景）、#FFFFFF（卡片背景）
- 边框色：#E8E8E8
```

### 8.2 字体规范
```
- 标题字体：24px/20px/18px/16px
- 正文字体：14px
- 辅助文字：12px
- 字体族：-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif
```

### 8.3 间距规范
```
- 页面边距：24px
- 卡片内边距：24px
- 元素间距：16px/12px/8px
```

### 8.4 圆角规范
```
- 卡片圆角：8px
- 按钮圆角：4px
- 输入框圆角：4px
- 头像圆角：50%（圆形）
```

## 九、交互规范

### 9.1 加载状态
```
- 页面加载：骨架屏
- 按钮加载：旋转图标 + 禁用状态
- 列表加载：加载更多提示
```

### 9.2 空状态
```
- 无数据：插图 + 提示文字 + 操作按钮
- 无搜索结果：插图 + "未找到相关结果"
```

### 9.3 操作反馈
```
- 成功操作：绿色Toast提示
- 失败操作：红色Toast提示
- 确认操作：模态框确认
```
