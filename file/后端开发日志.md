## 四、问题记录

### 问题1：Maven 依赖版本冲突

| 项目 | 内容 |
|------|------|
| 发生时间 | 2026-09-10 15:30 |
| 问题描述 | 父工程 POM 中 Spring Cloud 与 Spring Boot 版本不兼容 |
| 原因分析 | Spring Cloud 2021.x 需要配合 Spring Boot 2.7.x 使用 |
| 解决方案 | 固定 Spring Boot 版本为 2.7.18，Spring Cloud 版本为 2021.0.8 |
| 状态 | ✅ 已解决 |

### 问题2：MyBatis-Plus 分页插件未配置

| 项目 | 内容 |
|------|------|
| 发生时间 | 2026-09-10 16:05 |
| 问题描述 | 分页查询接口报错 "PaginationInterceptor not found" |
| 原因分析 | MyBatis-Plus 3.5.x 需要显式注册分页插件 |
| 解决方案 | 创建 MybatisPlusConfig 类注册 PaginationInnerInterceptor |
| 状态 | ✅ 已解决 |

### 问题3：Gateway 路由转发 404

| 项目 | 内容 |
|------|------|
| 发生时间 | 2026-09-10 16:20 |
| 问题描述 | 通过网关访问微服务接口返回 404 |
| 原因分析 | 路由配置中 path 匹配规则缺少 lb:// 前缀 |
| 解决方案 | 修改路由配置使用 `lb://服务名` 进行负载均衡转发 |
| 状态 | ✅ 已解决 |

### 问题4：JWT Token 验证失败

| 项目 | 内容 |
|------|------|
| 发生时间 | 2026-09-10 16:45 |
| 问题描述 | 网关鉴权过滤器报错 "Invalid JWT token" |
| 原因分析 | JwtUtils 中密钥配置与 AuthFilter 中不一致 |
| 解决方案 | 统一使用 Constants.SECRET_KEY 常量 |
| 状态 | ✅ 已解决 |

### 问题5：Feign 调用超时

| 项目 | 内容 |
|------|------|
| 发生时间 | 2026-09-10 17:10 |
| 问题描述 | recommend-service 调用 job-service 超时 |
| 原因分析 | 默认 Feign 超时时间过短，且未配置连接池 |
| 解决方案 | 增加 Feign 超时配置，启用 httpclient 连接池 |
| 状态 | ✅ 已解决 |

### 问题6：Nacos 服务注册失败

| 项目 | 内容 |
|------|------|
| 发生时间 | 2026-09-10 17:30 |
| 问题描述 | 微服务启动后无法在 Nacos 控制台看到注册信息 |
| 原因分析 | bootstrap.yml 中未配置 Nacos 地址 |
| 解决方案 | 添加 bootstrap.yml 配置 spring.cloud.nacos.server-addr |
| 状态 | ✅ 已解决 |

### 问题7：Knife4j 文档无法访问

| 项目 | 内容 |
|------|------|
| 发生时间 | 2026-09-10 18:00 |
| 问题描述 | 访问 /doc.html 返回 404 |
| 原因分析 | Gateway 路由未放行 Knife4j 静态资源路径 |
| 解决方案 | 在 AuthFilter 中添加 /doc.html, /webjars/** 白名单 |
| 状态 | ✅ 已解决 |

## 十一、开发规范

### 代码规范
- 分层架构：Controller → Service → Mapper → Entity
- DTO（请求体）与 VO（响应体）分离
- 使用 Lombok 简化实体类代码
- 使用 MyBatis-Plus 注解简化 SQL

### Git提交规范
- feat: 新功能
- fix: 修复bug
- docs: 文档更新
- style: 代码格式调整
- refactor: 代码重构
- test: 测试相关
