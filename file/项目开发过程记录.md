## 四、功能模块映射

### 4.1 用户模块 → user-service

| 功能点 | 接口 | Controller |
|--------|------|------------|
| 手机号注册 | POST /api/user/register | UserController |
| 账号登录 | POST /api/user/login | UserController |
| 个人中心 | GET/PUT /api/user/info | UserController |
| 密码管理 | PUT /api/user/password | UserController |

### 4.2 企业模块 → company-service

| 功能点 | 接口 | Controller |
|--------|------|------------|
| 企业认证 | POST /api/company/audit | CompanyController |
| 企业信息 | GET/PUT /api/company/info | CompanyController |

### 4.3 职位模块 → job-service

| 功能点 | 接口 | Controller |
|--------|------|------------|
| 岗位搜索 | GET /api/job/search | JobController |
| 岗位详情 | GET /api/job/{id} | JobController |
| 职位发布 | POST /api/job/publish | JobController |
| 职位管理 | PUT /api/job/update | JobController |
| 岗位收藏 | POST /api/job/favorite | FavoriteController |

### 4.4 投递模块 → application-service

| 功能点 | 接口 | Controller |
|--------|------|------------|
| 简历管理 | CRUD /api/resume | ResumeController |
| 简历投递 | POST /api/application/submit | ApplicationController |
| 投递记录 | GET /api/application/list | ApplicationController |
| 投递处理 | PUT /api/application/handle | ApplicationController |

### 4.5 推荐模块 → recommend-service

| 功能点 | 接口 | Controller |
|--------|------|------------|
| 获取推荐 | GET /api/recommend/jobs | RecommendController |
| 刷新推荐 | POST /api/recommend/refresh | RecommendController |
| 推荐记录 | POST /api/recommend/click | RecommendController |

## 七、启动说明

### 7.1 环境要求
- JDK 17
- Maven 3.8+
- MySQL 8.0
- Redis
- Nacos 2.2.x

### 7.2 启动顺序
1. 启动 Nacos 注册中心
2. 启动 MySQL 和 Redis
3. 创建数据库（job_user_db, job_company_db, job_job_db, job_application_db, job_recommend_db）
4. 执行 SQL 脚本初始化表结构
5. 按顺序启动服务：
   - gateway-service (8080)
   - user-service (8081)
   - company-service (8082)
   - job-service (8083)
   - application-service (8084)
   - recommend-service (8085)

### 7.3 接口测试
- Swagger 文档地址：http://localhost:{port}/doc.html
- 网关统一入口：http://localhost:8080/api/**
